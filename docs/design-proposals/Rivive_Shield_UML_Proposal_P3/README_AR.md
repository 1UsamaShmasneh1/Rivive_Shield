# مقترح P3 لمراجعة تصميم Rivive Shield

**الحالة: مسودة للمراجعة، غير معتمدة. لا تستبدل P2 ولا تمنح إذن تنفيذ أو نشر.**

هذا المقترح يجمع القرارات الجديدة في نموذج واحد: تطبيق حجز مستقل (React + C++ HTTP + SQLite)، ومصحح C++ بواجهة سطح مكتب، ومراقبة سلبية محلية مع قواعد تشخيص ثابتة. يستند إلى P2 المعتمد سابقًا وإلى تجارب الجدوى على Windows، لكنه ليس تنفيذًا للمشروع.

## ابدأ بهذه الملفات
- `IMPLEMENTATION_READINESS_AR.md`: حدود التحقق وموانع تجميد التنفيذ.
- `STATE_AND_API_REVIEW_AR.md`: الحالات المعتمدة وانتقالاتها المقترحة ومسارات الحجز.
- `docs/TECHNICAL_ASSUMPTIONS.md` و`schemas/`: افتراضات تقنية ومخططات أولية، لا تنفيذ مكتمل.
- `DECISIONS_AR.md`: ملخص عربي مختصر للقرارات المطلوبة قبل التعديل الموحّد.
- `docs/REVIEW_DECISIONS.md`: القرارات التي تحتاج مراجعة، وما لم تثبته التجارب.
- `docs/P2_DELTA.md`: ما احتُفظ به وما تغير صراحة عن P2.
- `docs/BEHAVIOR_AND_GATES.md`: شروط التنفيذ والموافقة والتخزين والخيوط.
- `docs/EXACT_CATALOG.md`: كل كلاس/struct مع حقوله ودواله، بما فيها الخاصة.
- `contracts/p3_draft.hpp`: نسخة C++17 تصريحية قابلة لفحص syntax فقط.
- `diagrams/`: UML نصي ومخططات SVG لكل نوع، وoverview للحدود بين المكونات.

## طريقة قراءة المسودة
الأسماء والحقول والدوال الجديدة كلها **مقترحة** وليست موافقة سابقة من أسامة. لا يضيف العضو helper أو field خارج العقد بعد اعتماده؛ إن احتاجها، يطرح تغيير UML أولًا. حتى المطابقة الكاملة للرسم لا تثبت صحة التنفيذ، وتبقى مراجعة الكود والاختبارات لازمة.

الـstructs هي قيم بيانات مشتركة وليست 67 وحدة عمل منفصلة. تقسيمها يمنع استخدام نصوص غير منظمة لتمرير الأدلة أو الموافقات. الأنواع الخارجية مثل SQLite/pcap/llhttp/wxWidgets ليست كلاسات مشروع جديدة.

## ما تحقق فعليًا
تجارب Windows المشار إليها في سجل المشروع نجحت في حدودها، ومنها HTTP المقسم والناقص و500 وعدم الرد وPOST/GET المتتابع، وقراءات PID الحالية، وعمليات فرعية مملوكة، وSQLite. ملف العقود في هذه الحزمة اجتاز فحص C++17 تصريحيًا على GCC في بيئة الإعداد؛ **لم يُربط أو يشغّل كتطبيق**.

Mac **قيد التحقق**. لا توجد في هذه الحزمة نتيجة نجاح لأمين. لا تزال GUI على Mac ونسبة حزم الشبكة إلى PID وآلية إدارة Oracle البعيدة مسائل غير مثبتة. لا تحوّل نجاح تجارب محلية إلى قبول نظام متكامل.
